# Changelog

## 0.1.2 — 2026-11-12

- Discover project startup services, Moon tasks, workspace scripts, documented Compose preparation, and confirmed ports without project-specific rules.
- Read existing check commands and tool configurations instead of enforcing built-in code policies; discover local CI/CD entries and GitHub workflows in one view.
- Simplify AI configuration through contextual instructions for existing AI tools, and start shared rules and files empty until users add them.
- Rename the worktree tab to Branches and workspaces and defer cleanup inspection until requested, improving initial loading while preserving deletion safeguards.
- Upgrade MyGo, its CLI, and the frontend runtime together from 0.8.3 to 0.9.0.
- Add signed in-place desktop updates, daily checks, and update actions in Settings and the app menu; preserve project data and keep development builds separate.
- Publish the macOS Apple Silicon installer and signed update feed only after signature verification and an in-place update smoke test.

## 0.1.1 — 2026-11-12

- Added saved startup, default page, overview refresh, text size, and motion preferences.
- Added version, documentation, issue, and release links to Settings.
- Simplified the English and Chinese READMEs; moved detailed usage into guides.
- Restored the original project commit history with private email addresses removed.

## 0.1.0 — 2026-11-12

Initial public preview of repsync.

- Local project registration and cloning, service control, port allocation, and CI/CD run history.
- Worktree, branch, and stash inspection with guarded local cleanup and recovery.
- Markdown preview, editing, draft preservation, and document search.
- Shared rules and reusable shared files with previews, adoption records, backups, and restore.
- Local AI resource inventory, available usage evidence, sourced project memory, and Codex / Claude Code session extraction.
- Project review records for checks, delivery stages, data, and handoffs.
- English interface, CLI, and public documentation; retained Chinese reference guide.
- GitHub CI, isolated browser demo, and a macOS Apple Silicon preview package.

This is development software. The macOS package is ad-hoc signed and not notarized. Other desktop platforms are not validated. See the README for supported operations and limits.

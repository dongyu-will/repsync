# Security

repsync can read local repositories, run configured commands, and update explicitly selected files. Preview builds should be treated as development software.

Please do not post credentials, private repository contents, local AI conversations, or exploit details in public issues. Report sensitive vulnerabilities using the repository's **Security → Report a vulnerability** option when available. If private reporting is unavailable, open a minimal issue requesting a private reporting channel without disclosing the vulnerability.

Include the affected commit or release, platform, reproduction conditions, impact, and a minimal redacted example. No response-time guarantee or long-term supported release branch is currently offered.

Keep Git, Go, Node.js, and optional AI tools maintained. Only run project commands and enable MCP integrations you trust. Session extraction may send selected text to the AI provider configured by your chosen CLI; review the selection before proceeding.
